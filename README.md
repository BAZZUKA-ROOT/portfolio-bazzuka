# Portfólio Bazzuka

Portfólio público de desenvolvimento e projetos de software, com Three.js, GSAP e layout responsivo.

**Site:** https://bazzuka-root.github.io/portfolio-bazzuka/

## Funcionalidades

- Apresentação profissional e tecnologias utilizadas.
- Vitrine de repositórios públicos com descrições, tópicos e links para o GitHub.
- Layout responsivo para desktop e dispositivos móveis.
- Animações e componentes interativos.

## Estrutura

- index.html: página principal.
- index.php: entrada alternativa do projeto.
- assets/: recursos visuais e catálogo de projetos.

## Atualização do catálogo

O Gestor de Projetos Bazzuka sincroniza os arquivos assets/projects.json e assets/projects-sync.js com os repositórios públicos do GitHub.
